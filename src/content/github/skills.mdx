## 项目介绍

Google Skills 是 Google 维护的 [Agent Skills](https://agentskills.io/home) 官方合集，面向 Google 产品与技术（以 Google Cloud 为主，并延伸 Ads、Analytics 等）。技能以 Markdown 工作流编码认证、上云、架构方案与运维护栏，安装后可被 Claude Code、Codex、Cursor 等兼容宿主按需激活。仓库仍在活跃迭代，同时捆绑部分「Skills + MCP」插件。

## 核心特性

- **按需安装**：`npx skills add google/skills`，交互式勾选本仓技能子集，不必一次装全
- **GCP 入门与鉴权**：认证、Foundation Builder、上云 onboarding 等「Getting started」配方
- **多产品方案技能**：解决方案架构、RAG、GKE Inference 迁移、无服务器 n-tier、双向流式 Agent 等端到端流程
- **领域纵深**：Agent Platform / Gemini、GKE 基建与排障、BigQuery·AlloyDB 等数据、WAF 六支柱、Logging/Monitoring、Cloud Run / Firebase、Ads SDK 与 Analytics API
- **宿主插件**：Claude Code、Codex、Antigravity CLI 可从本仓安装 Google 产品插件（Skills + MCP）

## 对用户价值

让 Agent 写 `gcloud`、搭 GKE、配 BigQuery 或接 Ads SDK 时，最常见的问题是过时语法、臆造 flag、跳过鉴权与安全护栏。本仓库把官方流程与「先查 help / 先验证再执行」一类约束写进可安装技能：你描述目标后，助手按对应技能走认证、清单与排障步骤，而不是凭训练记忆硬猜。对云原生与广告技术团队，相当于把分散文档收敛成可复用的 Agent 工作流。

## 与替代方案

- 相比 [Superpowers](https://github.com/obra/superpowers) 等通用研发方法论技能库，本仓聚焦 **Google 产品操作与架构配方**，不覆盖 brainstorming / TDD 全生命周期。
- 相比手写 Cursor Rules 或粘贴 Cloud 文档片段，这里提供可勾选、可更新的官方技能包，并与 [agentskills.io](https://agentskills.io/home) 格式对齐；Flutter / Dart / ADK 等另有独立 skills 仓（README「Additional Google skills」）。
- 相比只装 MCP 而无流程约束的集成，本仓技能强调步骤与护栏（例如 gcloud 技能要求先 `gcloud help` 校验叶子命令）；若你只需原始 API 调用且不经过 Agent，直接读官方文档即可，不必安装。

## 适应人群

- 用 Claude Code、Codex、Cursor 等日常操作 GCP / GKE / BigQuery，希望减少错误 CLI 与漏配的云工程师。
- 需要把「官方推荐架构与上线清单」固化进 Agent 行为的平台 / SRE / 解决方案架构师。
- 做 Google Ads、Mobile Ads 或 Analytics API，想让助手按官方 quickstart 与诊断流程推进的应用开发者。

## 如何使用

### 前置条件

- 已安装 Node.js（用于 `npx skills`），或目标 Agent 宿主支持本仓插件安装方式。
- 操作 Google Cloud 时需本机或 CI 具备有效凭据（如 `gcloud` 登录 / ADC）；Ads / Analytics 技能另需对应 API 访问权限。
- 确认宿主兼容 [Agent Skills](https://agentskills.io/home) 或 README 列出的插件路径；仓库标注为积极开发中，技能集合会持续增减。

### 安装方式

**skills.sh / npx（通用）**

```bash
npx skills add google/skills
```

安装过程中按提示选择需要的具体技能。

**Claude Code 插件**

```bash
claude plugin marketplace add google/skills
claude plugin install <plugin>@google-plugins
```

**Codex**

```bash
codex plugin marketplace add google/skills
# 再在 /plugins 浏览器中安装所需插件
```

**Antigravity CLI**

```bash
agy plugin install https://github.com/google/skills/<plugin-path>
```

将 `<plugin-path>` 替换为仓库内实际插件路径（见 README Plugins 表）。

### 首次运行

1. 仅勾选当前任务相关技能（例如鉴权 + gcloud，或某一 GKE / BigQuery 技能），避免上下文过载。
2. 在 Agent 会话中描述具体目标（如「创建带私有网络的 Cloud Run 服务」或「排查 GKE JobSet 中断」），确认对应技能被激活。
3. 涉及云变更时先在非生产项目演练；按技能要求完成鉴权与语法校验后再执行写操作。

### 验证是否成功

- `npx` 安装完成后，宿主的 skills / plugins 列表中能看到所选 Google 技能。
- 发起与技能匹配的请求后，助手应引用技能步骤（例如先跑 `gcloud help …`、给出清单式计划），而非直接输出未校验的长命令。
- 只读探测（如 `gcloud config get-value project`、列出集群）可成功；再逐步验证写操作。

### 常见坑 / 注意事项

- **仓库仍在活跃开发**：技能路径与覆盖范围可能变化，升级后核对所选技能是否仍存在。
- **按需安装**：全量装入易挤占上下文；优先最小子集。
- **凭据与权限**：技能不会替你绕过 IAM；缺权限时先修角色，不要反复重试破坏性命令。
- **gcloud 幻觉**：相关技能明确要求先查叶子级 `gcloud help`，不要跳过校验直接执行。
- **姊妹仓库**：Flutter、Dart、Firestore、ADK、进阶 GCS 等技能在其他官方仓，本仓 README「Additional Google skills」有链接。
