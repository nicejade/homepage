## 项目介绍

free-claude-code（FCC）是独立开源的本地代理与 Admin 管理台：把免费、付费、订阅与本地模型收进同一可搜索目录，驱动 Claude Code、Codex、Pi、OpenCode、Cline、Hermes、DeepSeek Harness、Grok Build、Muse Code 九款编程 Agent。官方宣称覆盖约 50 个 ToS 友好供应商、月级 1.3B+ 免费 token，并强调遵循各家条款、不合规即移除集成。项目与 Anthropic 无隶属关系，MIT 许可。

## 核心特性

- **多供应商、一目录**：免费 / 付费 / 订阅 / 本地（Ollama、LM Studio、llama.cpp）统一配置；重试耗尽后可按 Fallback Models 自动换下一家，客户端无需重开回合
- **九款 Agent 一套模型目录**：`fcc-claude`、`fcc-codex`、`fcc-pi`、`fcc-opencode` 等启动器，支持流式、工具调用、交错 thinking、图片，以及按 Fable / Opus / Sonnet / Haiku 分层路由
- **终端到手机**：原生启动器、VS Code、Codex App、JetBrains、Discord / Telegram；可选语音输入（本地 Whisper 或 NVIDIA NIM）
- **省 token 与可选 RTK**：配额探测、命令前缀、标题与路径等本地优化；可选 [RTK](https://github.com/rtk-ai/rtk) 过滤常见终端输出
- **Admin UI 一站配置**：密钥校验、模型下拉、代理鉴权、Reasoning 力度与 Messaging 集成

## 对用户价值

官方 Claude Code / Codex 体验好，但订阅与 API 成本高，换模型又常要改多处配置。FCC 让你继续用熟悉的 Agent 宿主，却能接 NVIDIA NIM、OpenRouter、Groq、ChatGPT 订阅、本地 Ollama 等；供应商宕机时自动 fallback，不必中断当前回合。对想先用免费额度试跑、或把本地模型接到现有工作流的人，它是「换上游、不换 Agent」的入口。

## 与替代方案

- 相比 **opencodex**：opencodex 侧重把 Codex / Claude Code 请求翻译到任意 LLM；FCC 更偏「装齐多 Agent + Admin 管供应商/模型/消息」，覆盖面更广，也更强调 ToS 友好目录。
- 相比 **CC Switch**：CC Switch 是桌面配置管理（托盘快切供应商、MCP/Skills）；FCC 是运行时本地代理与模型目录，负责实际转发与 fallback。
- 相比直接改各 CLI 的 `BASE_URL` / 第三方中继：FCC 提供安装器、启动器、Admin 校验与可选语音 / IM；代价是引入本地守护进程与额外配置面。
- 若你只需单一官方订阅、从不换模型，直接官方登录更轻量，无需 FCC。

## 适应人群

- 日常用 Claude Code / Codex，想接免费额度、第三方 API 或本地模型控成本的开发者。
- 同时维护多款编程 Agent，希望一套模型目录与统一 Admin 的效率型用户。
- 需要 Discord / Telegram / 语音入口远程下任务，又希望工作目录与权限可控的个人用户。

## 如何使用

### 前置条件

- macOS / Linux / Windows；安装脚本会拉起依赖（README 标注 Python 3.14、uv）
- 至少一个可用凭证：如 [NVIDIA NIM API Key](https://build.nvidia.com/settings/api-keys)，或其他供应商 Key / ChatGPT 连接 / 本地推理服务
- 使用对应 Agent 前需已安装或由安装器一并选择 Claude Code、Codex、Pi、OpenCode 等

### 安装方式

macOS / Linux：

```bash
curl -fsSL "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.sh" | sh
```

Windows PowerShell：

```powershell
& ([scriptblock]::Create((irm "https://raw.githubusercontent.com/Alishahryar1/free-claude-code/main/scripts/install.ps1")))
```

提示时至少选一款编程 Agent；可选 RTK。同一命令可重复执行以更新。安装脚本可先审阅：[`install.sh`](https://github.com/Alishahryar1/free-claude-code/blob/main/scripts/install.sh)、[`install.ps1`](https://github.com/Alishahryar1/free-claude-code/blob/main/scripts/install.ps1)。

### 首次运行

1. 启动 FCC：Windows / macOS 打开 **Free Claude Code** 桌面入口；Linux 运行 `fcc-server`（保持终端开启）。日志会给出 Admin UI 地址；托盘 / 菜单栏可开关 Admin。
2. 在 Admin 中配置供应商（Quick Start 默认走 NVIDIA NIM）：粘贴 `NVIDIA_NIM_API_KEY`，`MODEL` 可用默认 `nvidia_nim/nvidia/nemotron-3-super-120b-a12b`，点 **Validate** → **Apply**。
3. 启动 Agent，例如：

```bash
fcc-claude
fcc-codex
fcc-pi
fcc-opencode
```

也可在 Claude Code 原生 `/model` 选择器里选 FCC 模型。需要代理鉴权时，在 Admin 开启 **Proxy Authentication**。

### 验证是否成功

- `fcc-server --version` 能打印版本（不启动服务）
- Admin UI 可打开，供应商 **Validate** 通过
- `fcc-claude`（或你选的启动器）能完成一次简单对话 / 工具调用，无阻塞性鉴权错误
- 若配了 Fallback Models，可人为关掉主供应商，确认请求会落到下一模型

### 常见坑 / 注意事项

- **独立项目，非 Anthropic 官方**：商标与品牌归属 Anthropic；免费额度与限额由各供应商控制，可能随时变化
- **端口与 token 要对齐**：IDE / Codex App 里的 `ANTHROPIC_BASE_URL`、鉴权 token、模型 ID 必须与 Admin 一致；改完后重启 Agent / IDE
- **Claude Code 仍提示登录**：按 README 在 `~/.claude.json`（Windows 为 `%USERPROFILE%\.claude.json`）写入 `hasCompletedOnboarding: true`
- **Coding Plan 类 Key 不可混用**：如 Kimi Code vs Kimi API、QwenCloud Coding vs Token Plan，前缀与条款不同，仅适合个人交互式编码场景
- **本地模型要够上下文且支持工具**：否则 Agent 系统提示与 tool schema 容易撑爆或无法调用
- **卸载**：先停掉所有 FCC 进程，再跑官方 uninstall 脚本；会删除 `~/.fcc/` 与启动器，但保留 uv/Python 与各 Agent 本体
