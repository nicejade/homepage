## 项目介绍

[agency-agents](https://github.com/msitarzewski/agency-agents)（The Agency）是一套开源的 **AI 专家人格库**：把前端、后端、安全、测试、市场、产品等角色写成可安装的 Markdown Agent，每个角色带人设、流程、交付物与成功指标，而不是一句「扮演某某」的空提示。仓库提供桌面应用 [Agency Agents](https://agencyagents.app) 与 `convert.sh` / `install.sh`，可把同一批 Agent 分发到 Claude Code、Cursor、Codex、Gemini CLI、OpenCode 等主流宿主。

## 核心特性

- **230+ 专科 Agent**：按 Engineering、Design、Marketing、Security、Testing、Product 等部门组织，覆盖编码到增长、合规等场景
- **人格 + 流程 + 交付物**：每个文件含身份声线、工作流、代码/文档示例与可衡量成功标准
- **跨宿主安装**：原生支持 Claude Code / Copilot；`./scripts/convert.sh` + `./scripts/install.sh` 可转成 Cursor rules、Codex agents、OpenClaw 人格包等
- **桌面应用一键装**：macOS / Linux / Windows 原生 App 浏览花名册并写入各工具目录，支持自动更新（亦可 `brew install --cask`）
- **按需裁剪**：`--division` / `--agent` 只装需要的团队或单个 Agent；OpenCode 等有上限的宿主可避免一次装爆

## 对用户价值

通用 Agent 往往「什么都会一点」，却缺少稳定的角色边界与交付标准。The Agency 把「找前端写 UI、找 Reality Checker 做上线门禁、找营销写社区话术」变成可切换的专家模式：你在 Claude Code / Cursor 里激活对应 Agent，就能按该角色的流程产出代码、清单或方案。对小团队，相当于用提示资产拼出一支「不睡觉的虚拟顾问团」；对多工具用户，同一套人格可通过安装脚本同步到多个宿主，减少到处复制粘贴。

## 与替代方案

- 相比 [Agent Skills](https://github.com/addyosmani/agent-skills)、[Superpowers](https://github.com/obra/superpowers) 等 **工程方法论 / Skills 包**，本仓主打 **按部门划分的角色人格**（含市场、销售、医疗等非纯编码岗），不是 `/spec`→`/ship` 式全生命周期命令链。
- 相比自己维护 Cursor Rules 或零散「Act as…」提示，这里提供可浏览、可 PR 贡献、可按 division 安装的完整花名册，并有官方转换脚本对接多工具。
- 相比 LangGraph 等 **编排框架**，本仓交付的是可直接喂给现有编码 Agent 的人格文件，不负责运行时调度引擎；多 Agent 协作示例见仓库 `examples/`（如 Nexus 空间发现），编排逻辑仍由宿主承担。
- 边界：人格质量依赖模型与宿主执行；装全量可能噪声大——建议先装 `engineering` / `security` 等子集再扩展。

## 适应人群

- 使用 Claude Code、Cursor、Codex 等，希望按「前端 / 安全 / 测试」等角色切换专家模式的工程师。
- 小团队或独立开发者，需要市场、产品、项目管理等非编码角色提示资产做虚拟协作。
- 要在多个 AI 编程工具间统一同一套 Agent 人格，并可用 App 或脚本批量安装的效率型用户。

## 如何使用

### 前置条件

- 已安装至少一个目标宿主（Claude Code、Cursor、Codex、Gemini CLI、OpenCode 等）。
- 命令行安装需能 `git clone` 与执行 Shell 脚本；桌面 App 支持 macOS / Linux / Windows。
- 了解本仓是 **人格与流程资产**，不是独立运行的 Agent 服务；效果取决于宿主与所用模型。

### 安装方式

**方式一：桌面 App（推荐）**

从 [Releases](https://github.com/msitarzewski/agency-agents-app/releases/latest) 下载，或在 Mac 上：

```bash
brew install --cask msitarzewski/agency-agents/agency-agents
```

也可访问 [agencyagents.app](https://agencyagents.app)。

**方式二：Claude Code 脚本安装**

```bash
git clone https://github.com/msitarzewski/agency-agents.git
cd agency-agents
./scripts/install.sh --tool claude-code
# 或只拷某一部门：
# cp engineering/*.md ~/.claude/agents/
```

**方式三：多工具转换后安装**

```bash
./scripts/convert.sh
./scripts/install.sh                          # 交互选择已检测到的工具
./scripts/install.sh --tool cursor            # 或指定工具
./scripts/install.sh --tool claude-code --division engineering,security
./scripts/install.sh --list teams             # 查看团队与 Agent 数量
```

### 首次运行

1. 用 App 或 `install.sh` 装入目标宿主后，打开对应工具。
2. 在会话中显式激活角色，例如：`activate Frontend Developer mode and help me build a React component`。
3. 复杂项目可参考 README 用例（MVP、营销战役、企业功能）或 `examples/nexus-spatial-discovery.md` 的多 Agent 协作示例。

### 验证是否成功

- Claude Code：确认 `~/.claude/agents/`（或安装目标路径）出现对应 `.md`，会话中能按角色名切换。
- Cursor：确认项目或用户目录下生成 `.cursor/rules/` 相关规则文件。
- 安装器支持 `--dry-run`；OpenCode 若一次装过多，可能因上游约 119 个 Agent 上限静默丢弃——用 `--division` 减负后重装。

### 常见坑 / 注意事项

- **不要默认装全量**：部门众多，全量安装易造成规则冲突与上下文噪声；先按任务选 division / agent。
- **OpenCode 上限**：全量安装可能超过运行时注册上限，优先子集安装。
- **Aider / Windsurf** 等工具会合并为单文件约定（如 `CONVENTIONS.md`），与「每 Agent 一文件」体验不同，注意覆盖与体积。
- 人格与示例代码需结合你的仓库规范二次裁剪；商业使用遵循 MIT，署名感谢但非强制。
