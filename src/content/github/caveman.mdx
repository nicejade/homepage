## 项目介绍

Caveman 是装在本机上的编程 Agent 省 token 层。一条 `npx @caveman-ai/cli@latest` 会接上 Claude Code、Codex、Gemini CLI、OpenCode 等 30 多种工具，默认打开短回答和输入压缩等六块能力；代码、命令、路径和报错逐字保留，也不改写你自己的 prompt。只想要短回答时，可以单独装 skill，不启本地代理。

## 核心特性

- **说得少**：`/caveman`、`/ultracave`、`/megacave`（文言）三级。README 示例里，63 token 的解释压到 20 / 14 / 13，代码原样。相对「Answer concisely」，十道开发题上 `/caveman` 中位数再少约 3%，`/ultracave` 再少约 35%（按 3.1.0 规则测量，尚未用新规则重跑）。
- **读得少**：日志、JSON、CSV 和测试输出在进模型前先缩小。54 次 Claude Code 整段会话的输入 token 少 33.2%，18/18 答案仍对。
- **Auto**：按每次提问选模型和力度。相对 Opus 5.5 的 xhigh，85 道编程题的中期结果便宜约 54%、分数相同。六块里只有这块需要免费账号。
- **Blocks 与 Browse**：Blocks 把 Agent 写过的脚本留在仓库里复用（一次 `go test` 的回读从 397 token 降到 76）。Browse 把网页压给 Agent 读（一张 200 行表格的 Playwright 快照从 15,704 token 降到 121）。
- **本机开关**：`caveman status` 查看各块是否开启，`caveman off <名字>` 单独关掉。Skill 本体不上传内容；CLI 默认上报用量统计。

## 对用户价值

长会话的 token 主要耗在寒暄，以及把整段测试日志、JSON 再读一遍。Caveman 把「怎么说」和「读什么」分开压，Auto 则避免每问都走最贵的模型。仓库标语仍写「约省 65%」；更细的对照是：JetBrains 用 86 道真实编程题做配对测试，输出 token 少 8.5%，质量没有可测损失（p = 0.82）；Adobe 的 CAVEWOMAN 论文报告穴居人式输出在八个模型上便宜约 1.4–2.4 倍。Skill 规则本身大约占 1,160 输入 token。按次计费、回答长短不影响账单时（README 点名 GitHub Copilot），短回答省不到这笔钱。

## 与替代方案

- 相比手写「请简短回答」：README 把这句话当成真正基线。`/caveman` 在旧测量里只再少约 3% 输出；多出来的是可安装的分级、输入压缩、Blocks 和可选路由。
- 相比 [Headroom](https://github.com/headroomlabs-ai/headroom)：Headroom 专注进模型前压缩工具输出、日志和 RAG，形态是库、代理或 MCP。Caveman 的「读得少」和这一层重叠，另外还有回答风格、Auto 和 Blocks，并默认嵌进你已经在用的编程 Agent。
- 相比 [Superpowers](https://github.com/obra/superpowers) 这类流程 skill：Superpowers 编排任务怎么做，Caveman 压 token，两者可以同时装。
- **边界**：只要短回答，用 `npx skills add`，不必装整套 CLI。[Caveman Cloud](https://app.caveman.so/signup) 是给「你自己做的 Agent」做观测和评估的产品，和本机这套不是同一个安装目标。

## 适应人群

- 每天用 Claude Code、Codex、Gemini CLI 或 OpenCode，输出和工具回读都按 token 计费的人。
- 测试日志、JSON 或网页快照经常把上下文撑满的人。
- 只想要短回答、不想登录、也不想开本地代理的人。

## 如何使用

### 前置条件

- **Node.js 22.13+**（CLI 主路径）。
- 本机已安装至少一种支持的 Agent。完整矩阵见 [INSTALL.md](https://github.com/JuliusBrussee/caveman/blob/main/INSTALL.md)。
- macOS、Linux 或 Windows。4.0 之前装过的话，命令必须带 `@latest`，否则会继续用本机旧副本。

### 安装方式

**推荐：扫描本机 Agent 并安装整套 CLI**

```bash
npx @caveman-ai/cli@latest
```

安装器会列出将要改动的内容，回车确认。已装过可再跑 `caveman setup`。

**只要 Skill，不要代理**

```bash
npx skills add JuliusBrussee/caveman -g
```

**其他入口**

```bash
# Claude Code 插件，交互会话与子 Agent 自动启用
claude plugin marketplace add JuliusBrussee/caveman && claude plugin install caveman@caveman

# Gemini CLI
gemini extensions install https://github.com/JuliusBrussee/caveman

# 本机全部 Agent，并带上 Claude Code 状态栏（钉在 v4.0.1）
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/v4.0.1/install.sh | bash
```

```powershell
# Windows · PowerShell 5.1+
irm https://raw.githubusercontent.com/JuliusBrussee/caveman/v4.0.1/install.ps1 | iex
```

### 首次运行

- 装完 CLI 后，直接打开 `claude` 即带 Caveman；也可以 `caveman claude`（同样支持 `codex`、`gemini`、`opencode` 等）。
- Agent 里输入 `/caveman` 启用（Codex 为 `$caveman`）。说 `stop caveman` 或 `/caveman off` 关闭。
- 档位：`/caveman`、`/ultracave`、`/megacave`。`/caveman status` 查看当前模式。
- 要用 Auto，先 `caveman login`。`caveman status` 可看六块里哪些开着，例如 `caveman off browse` 只关网页压缩。

### 验证是否成功

- 让 Agent 解释一个技术问题，对比启用前后的长度；代码块、命令和报错应逐字不变。
- 终端跑 `caveman status`，确认它列出本机 Agent，以及各块开关。
- 在 Claude Code 里跑 `/caveman-stats`，或在终端跑 `caveman stats`，查看 token 记录。
- 想在自己的任务上对照：`caveman trial -- claude`。

### 常见坑 / 注意事项

- 仓库简介里的「65%」是标语。当前 README 以「请简短回答」为基线，语音档的额外收益更小；3% / 35% 那组数尚未用新规则重测。安全警告、不可逆操作和困惑的用户会恢复完整句子。
- Skill 规则大约增加 1,160 输入 token。GitHub Copilot 这类按请求计费时，回答变短并不省钱。
- CLI **默认遥测**：命令、token 数量、安装 ID、系统和 IP，不含 prompt、代码、路径或脚本正文。关闭：`caveman telemetry off` 或 `DO_NOT_TRACK=1`。`/caveman-compress` 会把你指定的文件发给已配置的模型供应商。
- Auto 登录并开启后，会把最近一次提问（含 Agent 附上的 `CLAUDE.md`、记忆或 @ 文件）、上一条提问，以及上一轮回复的末尾发到 Caveman Cloud。`caveman off routing` 可停。
- Blocks 仍是预发布（v0.1.0-rc.5），仅 Python，尚无沙箱；官方表里 `grep-defs` 输给裸 `grep`。Browse 对很小的表单可能更差（约 2.3 倍）。Waste fixes 和暖 prompt cache 标注为尚未测量。
- npm 12 会拦截 git 安装，用上面的 `@latest` 或钉死 v4.0.1 的一行命令。整套卸载：`npx -y github:JuliusBrussee/caveman -- --uninstall`（npm 12 再加 `--allow-git=root`）。只装了 skill：`npx skills remove JuliusBrussee/caveman -g`。
- 许可证为 Apache-2.0。「Caveman」名称和石头标志是商标。4.0 以前的 `lite` / `full` / `ultra` / `wenyan` 档位已由 `/caveman`、`/ultracave`、`/megacave` 接替。
